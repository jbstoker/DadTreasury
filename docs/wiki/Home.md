# 🌿 Dad's Treasury

> **A calm, private, offline-first family hub for Android.**

Dad's Treasury helps parents and children coordinate **tasks**, **rewards**, **wallet & time bank**, **calendar**, **chat**, **location reminders**, and a **family wiki** — all stored securely **on-device** with no cloud required.

## 🌟 Highlights

- ✅ **100% offline** — no internet needed for core features
- 🔒 **Encrypted** — SQLCipher + EncryptedSharedPreferences
- 👨👧 **Role-based** — parent controls, child completes
- 🧩 **Accessible** — calm mode, high contrast, text scaling, colorblind-safe
- 🕰️ **Dual calendar** — Gregorian + Natural 13-month
- 📡 **Extensible sync** — Meshtastic / Bluetooth / Wi-Fi Direct ready
