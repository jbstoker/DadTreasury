# 🔗 Connect Parent Apps

> Connect **two parent apps** so you can share the family wiki and message each other — fully offline.

---

## 🎯 Overview

Dad's Treasury lets **two parent apps** connect securely:

- 📖 **Share the wiki** — send library pages to another parent
- 💬 **Message each other** — send short messages parent-to-parent
- 🔒 **All data stays on-device** — sync events are queued locally

---

## 🔑 Creating a Connection

1. From the **Home** screen, tap **Connect** in the quick-nav grid
2. Tap the 🔗 **link icon** (top-right) to create a pairing code
3. Enter your **display name**
4. A **6-character code** is shown — share it with the other parent
5. The other parent opens **Connect** on their app and taps the **⌨️ input icon**
6. They enter your 6-character code and tap **Connect**

Both apps now show the connection as ✅ **Trusted**.

---

## 📖 Sharing the Wiki

1. Tap an existing connection in the list
2. Tap **Share Wiki**
3. Pick a wiki page from your library
4. The page is marked as **shared** with that connection

> 💡 The page is queued for sync. When the other parent's device connects, the page is delivered.

---

## 💬 Messaging Another Parent

1. Tap an existing connection in the list
2. Type a message in the text field
3. Tap **Send**

The message is stored in the encrypted local database and queued for delivery.

---

## ❌ Disconnecting

1. Tap a connection
2. Tap **Disconnect** to revoke access

---

## 🔒 Privacy & Security

- Connections use a **6-character pairing code**
- All data stays **on-device** / transport-encrypted
- Messages and shared wiki pages are stored inside the **encrypted SQLCipher** database
- **No cloud or server is required**

---

## 🧭 Where to Find It

| Role | Where |
|------|-------|
| 👨 **Parent** | Home grid → **Connect** |
| 🧒 **Child** | Not available (parent-only) |

> 🔒 Only the **parent** role can create, accept, or disconnect parent app connections.
