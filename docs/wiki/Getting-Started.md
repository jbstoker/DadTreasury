# 🚀 Getting Started & Roles

> **First run?** This guide walks you through setup and explains what each role can do.

---

## 🌿 First Launch

1. Tap **Dad's Treasury** to open the app
2. Choose your role:
   - 👨 **Parent** — manage tasks, rewards, calendar, pairing
   - 🧒 **Child** — see tasks, wallet, calendar, chat
3. Enter your name
4. Tap **Start using Dad's Treasury**

---

## 👨 Parent Can

- ✅ Create and manage tasks
- 👍 Approve or reject completed tasks
- 💰 Manage wallet and time rewards
- 📅 Manage calendar and events
- 💬 Chat with child
- 📍 Create location rules
- 🔗 Pair and revoke devices
- 🔗 Connect to another parent app (share wiki + message)
- ⏰ Grant screen time via Google Family Link
- 🛠️ View diagnostics

## 🧒 Child Can

- 👀 See assigned tasks
- 📷 Complete tasks (with photo!)
- 💰 View wallet and time rewards
- 📅 View calendar
- 💬 Chat with parent
- 📖 Read library pages
- 📍 View location rules and receive reminders

> **Children cannot** create tasks, add funds to their wallet, or edit the wiki.

---

## 🧭 Bottom Navigation

| Tab | Icon | What it shows |
|-----|------|---------------|
| **Home** | 🏠 | Dashboard with today's tasks |
| **Tasks** | ✅ | All tasks (or My Tasks for child) |
| **Wallet** | 💰 | Balance + transactions |
| **Calendar** | 📅 | Events + nature date |
| **Settings** | ⚙️ | Themes, accessibility, security |
