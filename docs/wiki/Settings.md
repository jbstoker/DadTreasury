# ⚙️ Settings

> Themes, accessibility, and security — all in one place.

---

## 🌈 Themes

Dad's Treasury ships with four visual themes:

| Theme | Style |
|-------|-------|
| 🚀 **Retro-Futurist** | Dark graphite + neon accents (default) |
| 🔆 **High Contrast** | Maximum readability |
| 🌿 **Calm** | Soft light theme, low stimulation |
| 🌲 **Nature** | Deep green, natural palette |

Tap a theme card to apply it instantly.

---

## ♿ Accessibility

| Option | What it does |
|--------|--------------|
| 🧘 **Calm Mode** | Reduces visual stimulation |
| 🐢 **Reduced Motion** | Minimizes animations |
| 🔆 **High Contrast** | Stronger color differences |
| 🔍 **Text Scale** | 80% – 150% slider |

No color-only meaning — every status also uses icons and labels.

---

## 🔒 Security

- **Set Up PIN Lock** — 4–8 digit PIN to protect the app
- **Change PIN** — update your existing PIN

See [Security](Security) for full details.
