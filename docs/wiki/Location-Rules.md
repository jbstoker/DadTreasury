# 📍 Location Rules

> Location rules trigger **local reminders** when the child enters an area.

---

## 🎯 What is a Location Rule?

A location rule contains:

| Field | Description |
|-------|-------------|
| **Title** | Name of the rule |
| **Message** | Text shown when triggered |
| **Latitude / Longitude** | Center of the area |
| **Radius** | How close you need to be |
| **Active hours** | When the rule is active |

When the child enters the area, the app can:
- 🔔 Show a notification
- 📝 Show a message
- ⏰ Create a reminder

---

## 🛠️ Adding a Location Rule (Parent Only)

1. Open **Locations** from the home grid
2. Tap **+** (top right) — hidden for child role
3. Fill in:
   - **Title**
   - **Message**
   - **Place name** (search or enter coordinates)
   - **Radius** (presets or custom)
   - **Active hours**
4. Tap **Create**

> 🔒 **Children can view** existing rules and receive notifications, but **cannot create or edit** them.

---

## 📍 Smart Place Search

You can type a place name like `Supermarket, Amsterdam` and Dad's Treasury will:
1. Geocode the area
2. Search for the brand inside a bounding box
3. Fill in the latitude/longitude automatically

No Google Play Services required — it uses the built-in Android Geocoder.
