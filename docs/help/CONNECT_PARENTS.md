# Connect Parent Apps

Dad's Treasury lets two parent apps connect securely so they can share the family wiki and message each other.

## Opening

- From the **Home** screen, tap **Connect** in the quick-nav grid.

## Creating a Connection

1. Tap the **link icon** (top-right) to create a pairing code.
2. Enter your display name.
3. A 6-character code is shown — share it with the other parent.
4. The other parent opens **Connect** on their app and taps the **input icon**.
5. They enter your 6-character code and tap **Connect**.

Both apps now show the connection as **Trusted**.

## Sharing the Wiki

1. Tap an existing connection in the list.
2. Tap **Share Wiki**.
3. Pick a wiki page from your library.
4. The page is marked as shared with that connection.

## Messaging Another Parent

1. Tap an existing connection in the list.
2. Type a message in the text field.
3. Tap **Send**.

The message is stored in the encrypted local database and queued for sync.

## Disconnecting

1. Tap a connection.
2. Tap **Disconnect** to revoke access.

## Privacy & Security

- Connections use a 6-character pairing code.
- All data stays on-device / transport-encrypted.
- Messages and shared wiki pages are stored inside the encrypted SQLCipher database.
- No cloud or server is required.
