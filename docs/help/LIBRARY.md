# Library

The Library is your private offline wiki — a calm place to store family knowledge, instructions, and reference pages.

## What Can You Store?

- Chore instructions
- Family rules
- School timetables
- How-to guides
- Anything you want to read later

## Categories

Categories help organize pages.

1. Open **Library**
2. Tap **📁** (Create category)
3. Enter a name
4. Tap **Create**

## Creating a Page

1. Open **Library**
2. Tap **+** (Add page)
3. Choose a category
4. Fill in:
   - **Title** (required)
   - **Content**
   - **Tags** (comma separated)
5. Tap **Create**

## Filtering by Category

Use the chips at the top:
- **All** — show every page
- Specific category — show only that category

## Reading a Page

Tap any page to open it in a reader dialog showing:
- Title
- Body text
- Revision number
- Tags

## Revisions

Every page keeps a history of changes. Each edit bumps the revision number, so you can always see which version you're reading.
