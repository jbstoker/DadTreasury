# Getting Started & Roles

Dads Treasury is a private, offline-first household coordination app for parents and children.

## First Launch

1. Tap 🌿 **Dads Treasury** to open the app
2. Choose your role:
   - 👨 **Parent** — manage tasks, rewards, calendar, pairing
   - 🧒 **Child** — see tasks, wallet, calendar, chat
3. Enter your name
4. Tap **Start using Dads Treasury**

## Parent vs Child

### Parent can
- Create and manage tasks
- Approve or reject completed tasks
- Manage wallet and time rewards
- Manage calendar and events
- Chat with child
- Create location rules
- Pair and revoke devices
- View diagnostics

### Child can
- See assigned tasks
- Complete tasks (with photo!)
- View wallet and time rewards
- View calendar
- Chat with parent
- Read library pages

## Bottom Navigation

| Tab | What it shows |
|-----|---------------|
| 🏠 Home | Dashboard with today's tasks |
| ✅ Tasks | All tasks |
| 💰 Wallet | Balance + transactions |
| 📅 Calendar | Events + nature date |
| ⚙️ Settings | Themes, accessibility, security |
