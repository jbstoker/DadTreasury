# Settings

The Settings screen controls how the app looks, feels, and protects your family.

## Themes

Dads Treasury ships with 4 themes — all designed for accessibility and calm.

| Theme | Look |
|-------|------|
| 🚀 Retro-Futurist | Dark graphite + neon cyan (default) |
| 🔆 High Contrast | Pure black + yellow/cyan, maximum visibility |
| 🌿 Calm | Soft light beige, muted green |
| 🌲 Nature | Deep forest greens |

Tap any theme to switch instantly.

## Accessibility

### Calm Mode
Reduces visual stimulation — ideal for sensitive users.

### Reduced Motion
Minimizes animations and transitions.

### High Contrast
Strengthens color differences beyond the theme's default.

### Text Size
Slide to scale text from 80% to 150%.

## Security

- **Set Up PIN Lock / PIN Lock Enabled** — see the Security manual for details
- Requires a 4-8 digit PIN
- PIN data is stored hashed in EncryptedSharedPreferences
